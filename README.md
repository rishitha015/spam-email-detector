# 📧 Spam Email Detector 🚫

This project uses **Machine Learning + NLP** to classify messages/emails as **Spam** or **Not Spam (Ham)**.

---

## ✨ Features
- Text preprocessing (cleaning + lowercasing + removing special characters)
- TF-IDF Vectorization
- Model training using Linear SVM (LinearSVC)
- Cross-validation for reliable accuracy
- Predict custom messages from user input

---

## 📊 Accuracy
- **Cross Validation Accuracy:** ~99.44%
- **Test Accuracy:** ~99.21%

---

## 🛠 Tech Stack
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- LinearSVC (Support Vector Machine)
